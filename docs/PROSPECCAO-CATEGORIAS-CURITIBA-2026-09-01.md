## Critério de publicação

As três empresas têm presença pública própria e informações suficientes para uma primeira página oficial. A implementação deve usar somente os serviços confirmados nas fontes, sem reproduzir telefone, e-mail, preços, avaliações ou horários no código público; esses canais devem ser ligados pelo funil server-only. Imagens de terceiros só entram após validação de uso; quando não houver asset reutilizável, gerar uma composição visual identificada como conceito.
