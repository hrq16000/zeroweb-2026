# Princípios de UI e UX

## UX

1. Cada página tem uma ação principal explícita.
2. Jornada: intenção → compreensão → confiança → solução → objeção → CTA.
3. Feedback imediato em toda ação; erro sempre recuperável.
4. Estados vazios instruem, não apenas informam.
5. Clareza acima de criatividade; nunca sacrificar compreensão por estética.

## UI

1. Hierarquia visual antes de ornamento.
2. Consistência de espaçamento, raio, peso e cor por token.
3. Densidade adequada ao contexto (marketing respira, painel concentra).
4. Identidade única por superfície: 0WEB no portal, cliente no `/portfolio`.
5. Performance faz parte do design: página bonita e lenta é página ruim.
